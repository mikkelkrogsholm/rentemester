## Important actual-source distinctions

* The selected intercompany/consolidation/eliminations dispatchers are **not** among the R54 shared early-405 fences. They classify any non-GET request as mutation. HEAD therefore checks mutation origin/cookie, selected company, content type/body and confirmation before unknown list suffix; Axum suppresses response bodies. HEAD is not a successful GET alias and must not be described as early405. No production changes were made.
* All selected HTTP POST handlers first deserialize an outer JSON Map and remove confirm, except elimination plan does not remove confirm. Thus public top-level positional tuples are not admitted. Nested non-flattened Serde structs can accept sequences; flattened interval structs are object grammar. MCP has the global arguments-object guard before leaf Serde; CLI/MCP bodies additionally pass SDK shape validation.
* Discovery schemas advertise patterns which the existing SDK domain validator does not implement. The SDK does implement object properties/required, enum/const, numeric bounds, array bounds and UTF8-byte string lengths. The schemas annotate byte bounds separately from JSON Schema character lengths. SDK preflight is not the native producer grammar, and neither implies source-domain validity.
* CLI schema inputs model normalized parsed argv plus stdin, not a public JSON input format. Global --local-profile supports split/attached syntax and installs a private Unix transport with exact origin and no TCP fallback. Generic remote guards precede family selectors. Service authentication is not admitted to these native lifecycle families.
* SDK request discards non-2xx bodies. Writes map 5xx and malformed/truncated/oversized successful replies to outcome_unknown. Elimination plan uses its separate read-only transport, maps send uncertainty to transport and retains only refusal HTTP status for non-2xx. No selected tool generates a key, actor, amount, ID or date.
* Current source producer success cores have distinct shapes. A consolidated report can return HTTP200/ok:true/status:blocked with null consolidatedFigures. Reconciliation has blocked, currency-mismatch and exact matched/mismatch rows. Monetary amounts and ore are strings, never locally summed by adapters. Raw source entry/line IDs are signed i64, not SDK safe-integer conversions.
