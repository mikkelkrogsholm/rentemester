# Read-only trial-balance implementation contract

Scope: the first Rust vertical slice (R03/R07/R08/R09/R10/R11). This refines action.report from the target architecture; it does not mark whole epic issues complete. The full baseline/hosted identity/native work remains open.

Input is an explicit local company directory, inclusive canonical YYYY-MM-DD from/to dates (year 0000 through 9999, real Gregorian dates). Whitespace is rejected at this new versioned CLI boundary; the legacy core's trimmed-validation/raw-query quirk is not copied. Existing TypeScript CLI/API output stays unchanged. This local operator has only OS file authority; no hosted membership/auth implementation is claimed. No network, actor mutation, migration or live workspace write occurs.

The source company directory and its data directory are opened as directory handles on supported Unix hosts. Final directory/file symlinks and nonregular sidecars are refused using no-follow descriptor-relative opens. The explicit company root is the capability boundary; operating-system aliases in its ancestor path are not a hosted authorization mechanism. Capture DB, WAL, SHM and rollback-journal twice; compare complete suffix/hash states, at most four attempts. Total copied source bytes are bounded to 512 MiB per capture. Temp files are private; SHM is not copied. Only the disposable copy may recover/checkpoint. Source handles are never opened writable. Cleanup is RAII on every path. Windows storage qualification is future work; unsupported platforms fail explicitly.

Read only a current company schema v36 with all exact raw-artifact migration id/name/SHA-256 triples. Refuse pending, missing, altered, gapped or newer history. On the same private snapshot check quick_check and foreign_key_check; require directly used column metadata and account enums. Do not claim full audit-chain, trigger/view or regulatory integrity: this is a bounded direct-table report, not system healthcheck.

SQL follows the current report: inner join all journal entries/lines/accounts, inclusive transaction dates, no status filter, independently round each line to øre, preserve touched zero-net accounts and distinct entry/line counts. Sort account numbers by UTF-16 code units to match JS sorting, not locale or Unicode scalar ordering. Debit-minus-credit is the balance for every account type. Invalid request and corrupt/unsupported input return a typed refusal.

Domain monetary values use unbounded integer øre (num-bigint), with resource-bounded decimal parser (2048 input bytes, exponent magnitude at most 400), half away from zero, exact two-place output strings and no negative zero. Legacy SQLite REAL values are decoded as f64, rejected if nonfinite, formatted with ECMAScript shortest-number spelling (ryu-js) and scaled exactly; never SQLite CAST or f64*100. INTEGER values outside JS safe integer range are refused as unsupported legacy precision, rather than silently copying lossy legacy conversion. TEXT/BLOB/NULL amounts are refused. This intentional fail-closed boundary is tested and does not imply a silent whole-product numeric migration. The new report format is rentemester-trial-balance/1 with exact-string money; it is not substituted under an existing numeric endpoint.

CLI is the new experimental rentemester-rust binary: trial-balance --company PATH --from DATE --to DATE. It emits one JSON line: success {ok:true,format,data}; operational refusal {ok:false,code,errors}, exit1; usage errors use the same refusal shape, exit2. Help is exit0. No unknown/duplicate flags, hidden company, writable fallback or automatic retry.

Acceptance: fixed money/date vectors; independently calculated synthetic totals; exact differential comparison to legacy for supported fixtures; boundary rounding, UTF-16 ordering, reversals across periods, empty periods and multiple companies; corrupt/gapped/newer/tampered histories, invalid amounts/FKs/types, missing/escaping/symlink source; WAL and source byte-inventory preservation; CLI usage/refusal exits; independent copy/concurrent-capture mutation negative controls. Rust formatting/clippy/tests and targeted legacy report tests must pass. No R01/R02/R03/R07/R08/R09/R10/R11 closure is implied by this bounded acceptance.
