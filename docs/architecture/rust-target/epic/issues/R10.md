Parent epic: #672. Phase: P1 — Rust foundation and first read-only vertical slice. Status: planned.

## Outcome

Read supported data without accidental migrations, WAL changes or adoption of unknown directories.

## Scope

- Open supported company and control schemas through an explicit read-only snapshot strategy

- Resolve workspace/company paths safely and reject symlink/path escape or unsupported schemas

- Expose consistent typed read queries and close handles deterministically
