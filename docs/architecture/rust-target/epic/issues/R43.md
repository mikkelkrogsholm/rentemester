## Outcome

Give installed clients safe, typed access to local and remote server contracts.

## Scope

- Implement version/capability negotiation, exact serialization, authenticated transport and binary streaming

- Scope connection/account/workspace/company caches and cancel stale reads on changes

- Represent uncertain writes distinctly from definite refusals and recover according to R05 per-operation retry matrix; retain original keys only where actually supported.

## Acceptance criteria

- [ ] Remote failure cannot trigger local fallback, blind retry or a new key for a key-idempotent operation; non-key operations use their specified read-back/provider reconciliation.

- [ ] TLS trust and credential redaction are verified; user-controlled server URLs cannot exfiltrate another profile credential
