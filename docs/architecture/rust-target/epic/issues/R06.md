## Outcome

Prove the native toolkit can serve accounting workflows before committing to full desktop implementation.

## Scope

- Pin/evaluate GPUI Kit and GPUI licenses/toolchain/platforms using official sources

- Prototype virtualized tables, keyboard/focus, accessibility, input/IME, file dialogs and PDF/evidence preview

- Assess macOS/Windows/Linux packaging and credential-store integration; preserve current visual identity

## Dependencies

- Requires #673 — Freeze the migration baseline and complete the feature/contract inventory

- [ ] A small read-only synthetic prototype is exercised on each claimed platform with recorded versions and limitations

- [ ] Keyboard/screen-reader, large-table and document-preview checks have observable results

- [ ] Any inability to meet the GPUI product direction is reported as a decision blocker, not silently replaced by another UI stack
