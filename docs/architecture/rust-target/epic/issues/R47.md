## Outcome

Make local desktop operation work without the user installing or managing a server.

## Scope

- Embed the existing React UI in the Rust/Tauri host; provide local/remote connection chooser, explicit workspace create/open and company navigation

- Package/start the compatible Rust runtime, await readiness and own shutdown/restart

- Use private ephemeral loopback credentials and verified ownership discovery; preserve user-selected data paths

## Acceptance criteria

- [ ] Fresh offline installation can create/open a synthetic local workspace without Bun/Node/Docker

- [ ] Two app instances, port collision, backend crash, upgrade interruption and unclean shutdown have recoverable outcomes

- [ ] Local secrets are not logged/persisted in ledger; remote failure never opens a local workspace automatically

- [ ] J01/J02 native onboarding covers company identity, VAT/non-VAT, shifted fiscal year, actor/account plan, bank mapping, import/opening balance and a clear path to first reviewed posting/report/verified backup; ordinary setup needs no JSON/CLI.

- [ ] App closure, sleep and restart show explicit local automation status and never promise background work without a separately installed, explicitly enabled supported service.

No live migration or unrelated new product capabilities. One authoritative writer per workspace; company-specific data stays in workspace configuration; checked-in acceptance data is synthetic. Preserve existing accounting/security/release gates. No live use before the cutover gate.

## Named owner acceptance scenarios

### J01 — Fresh local owner, VAT company

Given: Fresh qualified machine, no Bun/Node/Docker, synthetic VAT-registered company.

When: Install, choose data directory, configure identity/fiscal/VAT/account plan/bank, ingest receipt, review/post, inspect report and verify/export backup.

Then: Owner completes normal setup/accounting without JSON/CLI, exact report/evidence links and off-device recovery instructions are visible.

### J02 — Existing business, no VAT and shifted year

Given: Supported synthetic imported business, non-VAT configuration, shifted fiscal year and opening balances.

When: Import/restore with explicit mapping, review open items, post first expense and inspect period/report/backup.

Then: No invented VAT or duplicate opening balances; unresolved historical evidence blocks correctly and the owner gets the next action.

### J07 — Local closure/sleep versus hosted automation

Given: Explicitly enabled supported recurring/intake/backup tasks in local and hosted profiles.

When: Close app/sleep/change timezone or DST, then restart; revoke/cancel a queued task.

Then: Documented catch-up/skip and dispatch-authority policy, last/next/missed/pause/error visible, no implied unattended local service.
